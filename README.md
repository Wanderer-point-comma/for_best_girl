# новый сентябрь — визуальный референс

Одностраничный HTML-референс оформления, вдохновлённый настроением обложки
(зерно плёнки, дерево, выцветший розовый, тёмный деним) и текстом
«я бежал за твоим запахом, как в новый сентябрь».

## Запуск

Просто открой `index.html` в браузере — файл полностью самодостаточный
(шрифты подключаются с Google Fonts, аудиотрек встроен внутрь файла как
base64, внешних зависимостей нет).

Это визуальный референс, не финальный продакшн-сайт.
